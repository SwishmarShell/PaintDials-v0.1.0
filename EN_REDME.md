# PaintDIals v0.1.0

### External Tool for Paint Software.
### This version is target Paint Soft [ Krita ].

## Features
>- Link Paint Softwe [ Krita ]<br>
>- Link via the 'JSON file ( Command.json )'<br>

>- Number display + Radio botton + Color Change on Hover ( Hover UI )<br>
>- Real - time Brush Size Adjustment<br>
>- Real - time Opacity Adjustment<br>
>- Dial - based Control <br>
>- Digit ranges change values ( ±1 ) <br>

>- Mouse Wheel Support<br> 
>- Change values by while holding [ Ctrl key + Mouse wheel ] on dials<br>
